Advertising Sales Prediction using Linear Regression
Project Overview

This project uses Machine Learning to predict product sales based on advertising spending on TV, Radio, and Newspaper platforms. A Linear Regression model is trained to understand the relationship between advertising expenditure and sales.

Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Scikit-learn

Google Colab

Project Workflow

Loaded and explored the Advertising dataset.

Checked for missing values.

Separated advertising features from the target variable, Sales.

Split the data into training and testing sets.

Trained a Linear Regression model.

Evaluated the model using MAE, MSE, and R² score.

Visualized actual sales versus predicted sales.

Model Evaluation

Mean Absolute Error (MAE): 1.4651

Mean Squared Error (MSE): 3.1990

R² Score: 0.8986

The model achieved an R² score of approximately 0.90 on the test set, indicating that it explains about 90% of the variation in sales for this evaluation.

Conclusion

This project demonstrates how Linear Regression can be used to predict sales from advertising expenditure and how regression models can be evaluated using performance metrics and visualizations.
